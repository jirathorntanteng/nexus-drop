NEXUS DROP — Internet Transfer Prototype
==========================================

สิ่งที่มีในรุ่นนี้
- รหัสจับคู่ 6 หลัก หมดอายุประมาณ 10 นาที
- หน้า Blue Orb แบบ futuristic
- WebRTC DataChannel สำหรับส่งไฟล์ P2P เมื่อ NAT/firewall อนุญาต
- ใช้ public STUN servers เพื่อช่วยค้นหาเส้นทาง
- ส่งไฟล์เป็นชิ้น (chunks) โดยไม่ลดความละเอียด/ไม่บีบอัด
- รองรับหลายไฟล์ และดาวน์โหลดไฟล์ที่ได้รับจากหน้าเว็บ

ข้อจำกัดสำคัญ
- รุ่นนี้ยังไม่มี TURN server ที่ตั้งค่าให้พร้อมใช้ เพราะ TURN relay ฟรีที่เสถียรและไม่จำกัดไม่มีให้รับประกัน
- ถ้า P2P เชื่อมต่อไม่ได้ในบางเครือข่าย จะยังส่งไม่สำเร็จจนกว่าจะตั้งค่า TURN
- การส่งไฟล์ต้องเปิดหน้าเว็บค้างไว้ทั้งสองฝั่ง
- ไฟล์ที่รับจะอยู่ในหน่วยความจำของแท็บจนกดดาวน์โหลด ไม่ได้ถูกเก็บถาวรบนเซิร์ฟเวอร์
- ควรใช้ HTTPS บนโฮสต์สาธารณะ
- รหัส 6 หลักมีไว้จับคู่ ไม่ใช่การยืนยันตัวตนระดับสูง รุ่นทดสอบนี้ยังไม่มีบัญชี/การยืนยันผู้ส่ง
- ไม่ควรใช้กับไฟล์ลับหรือข้อมูลสำคัญจนกว่าจะเพิ่มการยืนยันตัวตนและการตรวจสอบความปลอดภัย

รันบนคอมเพื่อทดลอง
1. ติดตั้ง Node.js 18 หรือใหม่กว่า
2. แตก ZIP
3. เปิด Terminal/Command Prompt ในโฟลเดอร์นี้
4. รัน:
   npm install
   npm start
5. เปิด http://localhost:3000

เผยแพร่ให้ใช้คนละเครือข่าย
- นำโปรเจกต์นี้ไป deploy บน Node.js hosting ที่รองรับ WebSocket
- ต้องได้ HTTPS/WSS URL สาธารณะ
- ผู้ใช้ทั้งสองเครื่องเปิด URL เดียวกัน แล้วสร้าง/กรอกรหัส
- Free hosting อาจ sleep, จำกัดแบนด์วิดท์ หรือมีข้อจำกัดการใช้งาน

ตั้งค่า TURN (เมื่อมีผู้ให้บริการ TURN)
ตั้ง environment variables:
TURN_URL=turn:your-turn-host:3478
TURN_USERNAME=your-username
TURN_CREDENTIAL=your-password

หมายเหตุ: ไฟล์ public/index.html รุ่นต้นแบบนี้ใช้ STUN สาธารณะเป็นค่าเริ่มต้นและยังไม่ได้อ่านค่า TURN จากเซิร์ฟเวอร์
ก่อนใช้งานจริง ต้องเพิ่ม endpoint สำหรับส่ง TURN credentials แบบชั่วคราวไปยัง client และแก้ iceServers ในหน้าเว็บ
ห้ามฝัง TURN secret ถาวรลงใน JavaScript ที่ผู้ใช้ทุกคนเปิดดูได้

โครงสร้าง
- server.js             signaling server (WebSocket)
- public/index.html     UI + WebRTC client
- package.json          dependencies
